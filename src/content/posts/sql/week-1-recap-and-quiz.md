Week 1 is done, and you've already read data with your first queries. Let's make sure the foundations are solid before we go further, because everything else in this series builds on them.

This week covered:

SQL is the language for asking a database questions.\
A database is an organised, long-term store of data.\
Tables hold one kind of thing, with columns for details and rows for records.\
You can practise for free in a browser.\
SELECT reads data without changing it.\
Data types decide what a column can hold.
