Your queries can now search, handle missing values, rename columns and calculate. That's a useful set of skills already, and most everyday queries need nothing more than these.

This week covered:

LIKE matches patterns using % and _.\
NULL means unknown, and you test for it with IS NULL.\
COALESCE replaces a NULL with a fallback value.\
AS gives a column a clearer name in your result.\
Arithmetic lets you create new values as you read.\
Text functions clean up and reshape text.
