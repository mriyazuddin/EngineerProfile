Two sites can both run WordPress and be customised in entirely different ways. The reason is usually which type of theme they use.

Classic themes are the older approach. Their layouts are built in template files written in code, with design changes usually made through the Customizer, menus and widgets.

Block themes use blocks for the whole site, not just your content. Headers, footers and templates are all made from blocks and edited visually in the Site Editor.

To check which one you've got, look under Appearance. If you see Editor, you're using a block theme. If you see Customize, Widgets or Menus, it's more likely to be a classic theme.

Which should you choose? Starting a new site today, a block theme is a sensible default, since it lets you change more without code. Classic themes are still widely used and supported. If yours does the job, there's no rush to switch.

The block editor for writing posts and pages works with both types. The difference is in how you edit the rest of the site.

Go deeper: [Block themes guide](https://wordpress.org/documentation/article/block-themes/)
